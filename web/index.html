    When booking opens

    AWS says reservations open through the API on Oct 8 but has not said the time, so the default is the earliest moment, the start of Oct 8 in Pacific time. Change it if AWS announces a time. If you add a second round, sessions that were full are tried again then. The app also keeps checking on its own, so a wrong time does not stop it.

    How do I get the app password?
    1. Open myaccount.google.com/security and make sure 2-Step Verification is turned on. Google requires this before it will make app passwords.
    2. Open myaccount.google.com/apppasswords. Type a name such as Reinvent Sniper and click Create.
    3. Google shows 16 letters in four groups, like abcd efgh ijkl mnop. Copy them and paste them above. The spaces do not matter.
    4. That password can only send email for this app. You can delete it any time from the same Google page.

    Not using Gmail? Open Advanced below and enter your email provider's mail server, and use the password your provider gives for apps.

    Advanced (usually not needed)
